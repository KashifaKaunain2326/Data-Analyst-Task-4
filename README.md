# Data-Analyst-Task-4

Task 4: Dashboard Design

Data Analyst Internship

Objective

To design an interactive dashboard for business stakeholders using Power BI.

Tools Used

- Power BI Desktop
- Microsoft Excel
- Kaggle Dataset

Project Description

This project focuses on creating an interactive business dashboard to analyze sales and financial performance. It helps stakeholders understand business performance and make better decisions using visual reports.

Key Features

- Sales and Profit Analysis
- KPI Cards for Total Sales and Profit
- Interactive Slicers and Filters
- Monthly and Yearly Trend Analysis
- Data Visualization using Charts
- Consistent Dashboard Theme
- Easy Navigation

Dashboard Components

- KPI Cards
- Bar Charts
- Line Charts
- Pie Charts
- Slicers
- Summary Reports

Key Learnings

- Dashboard Design
- KPI Selection
- Data Visualization
- Interactive Reporting
- Business Performance Analysis
- Power BI Dashboard Development

Deliverables

- Interactive Power BI Dashboard
- PPT Summary
- Dashboard Screenshots

Conclusion

This project helped me understand how to create interactive dashboards, analyze business performance, and present meaningful insights to support business decisions.
